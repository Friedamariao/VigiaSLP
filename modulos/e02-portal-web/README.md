### Avance 3 — ISW2_E02_Avance3_Leos.rar

Entrega de construcción del portal web (ventana 23–25 nov 2026). Es un archivo `.rar` con:

- `ISW2_E02_Avance3_VigiaSLP.docx` — documento del Avance 3

Los archivos de cada avance van identificados por avance y con el apellido del líder al final (en este caso, Leos).
